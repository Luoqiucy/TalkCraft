# 火山ASR结束包依据

核实日期：2026-09-14。原始来源：[官方大模型流式语音识别API](https://www.volcengine.com/docs/6561/1354869?lang=zh)。直接访问正文失败，本轮经r.jina.ai只读文本代理读取该官方URL，代理并非官方SDK，未复制Demo代码。

接口协议表与最后音频请求示例均说明：audio-only类型2，最后包flags2且不附序号；音频序列化0、gzip1，长度为压缩后字节数。实现头为11 22 01 00，其后4字节大端压缩长度，随后gzip PCM。最后包携带最后一段实际音频，不重复发送该段。

普通音频同样使用raw序列化0，纠正原先沿用旧Arkitect默认JSON标记的问题。当前初始化仍采用此前固定Apache客户端的带正序号格式。

官方建议约100–200ms音频分块和发送间隔，本项目分块200ms已实现，第020轮已补默认200ms发送间隔，整体超时与取消覆盖等待过程。当前仅本机测试，官方兼容、鉴权以及最终识别效果仍须实测；最新官方页面支持新版单Key鉴权，本轮没有扩展该配置。
