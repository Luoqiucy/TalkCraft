# TalkCraft 定价网站预览

日期：2026-09-29。阶段：Phase 2 商业化。状态：可本地预览与独立静态构建，未发布、未注册收款。

用户要求先参考 Typeless 定价页的页面结构。TalkCraft 预览采用自己的品牌、文字和青绿色视觉；仅借鉴“三档套餐卡片→功能对比→常见问题”的信息组织，不复制对方价格、品牌资产、功能承诺或法律声明。

## 当前页面

- `pricing-site/` 为独立 React + Vite + TypeScript 页面，和桌面 React 工作台共用现有依赖，但不打包进 Windows EXE。
- 展示 Free、Pro、Team 三档**目标结构**。Free 预计免费；Pro 价格、月/年周期及具体额度待定；Team 在个人版稳定后评估。所有购买按钮明确禁用，不产生订单或付款。
- 功能对比区分“桌面开发版已支持”“商业网关开发中”和“团队后续规划”。FAQ 说明额度未确定、当前本机统计不是会员余额、订阅尚未开放，以及云端识别/模型的数据流。
- 页面带 `noindex,nofollow`，没有供应商 API Key、真实用户数据、结算脚本或第三方跟踪代码。未提供条款/隐私链接的假入口；正式公开销售前需补齐。

## 预览与交付

- 本机预览：`npm run pricing:dev -- --host 127.0.0.1 --port 4320`，浏览器打开 `http://127.0.0.1:4320/`。
- 类型检查：`npm run pricing:check`。静态构建：`npm run pricing:build`，输出 `dist/pricing-site/`，由 HTTPS 静态站点托管。不要直接双击构建后的 `file://` 页面；浏览器会限制模块加载。
- 正式域名和部署环境尚未决定，本轮没有发布到互联网，也没有改动 TalkCraft.exe。

## 上线购买入口前的门槛

1. 账号注册/登录与桌面安全会话；从桌面跳转网页后识别同一账号。
2. 服务端套餐权益和不可由客户端篡改的用量账本，公布转写与问答额度的计量、重置和超额规则。
3. 确定价格、币种、商户主体、支付渠道、续费/取消/退款流程和服务条款、隐私说明。
4. 支付通知验签、幂等和对账；服务端确认会员后桌面刷新权益。不能只凭浏览器支付成功页开通会员。
5. 公开前移除预览性质文案和 `noindex`，逐项核对页面所有权益与真实已上线功能一致。
