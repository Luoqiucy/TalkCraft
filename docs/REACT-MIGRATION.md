# React 前端迁移状态

更新：2026-09-25。仍属 Phase 1，阶段验收未完成。

## 入口与边界

- Tauri 主窗口配置为 `/react/`，React 19 + Vite 7 + TypeScript 5 负责工作台、历史、设置和桌面事件展示。
- 原生 `/` 保留为内部回退入口；原生 `/?hud=1` 继续负责透明 HUD。快捷键提示和问答独立窗口已迁移到 `/react/?panel=keymap` 与 `/react/?panel=chat`。透明命中区域属于 Rust 边界，不因为 React 页面替换而移植。
- Node.js 服务继续提供 ASR、文字模型、Agent、历史和诊断接口。天气且开启联网、LangGraph 开关与天气工具可用时走 `/api/agent`；其他联网问答走 `/api/search` 后 `/api/process`；普通问答只走 `/api/process`。听写不调用文字模型。
- React 不持有提供器密钥；密钥配置仍在本机服务端，API 返回不回显密钥。

## 已迁移

- 工作台四模式、翻译目标语言、提示词预设、联网开关、服务状态与独立首次使用说明。
- 复用原有录音会话状态机，支持权限等待取消、120秒限制、真实音量采样、回放、当前录音导出、转写预览及保留工作台草稿。工作台结束录音自动转写，后续文字处理手动触发；HUD/全局键录音自动按初始模式继续处理。
- 同一任务 ID 按顺序保存录音、转写、AI结果和错误；文字/音频保留策略仍由已有本机历史服务决定。保存失败不会清除当前工作台内容。
- 历史日期分组、筛选/搜索、加载更多、版本分别复制、录音回放、系统保存对话框原始格式/WAV导出、删除/撤销、保留设置、主动重试、反馈与可选本地诊断。
- 快捷键读取、编辑与保存；桌面关闭确认、最小化到托盘、HUD入口、BroadcastChannel状态与音量、全局快捷键事件、外部自动光标输出及工作台手动输入目标检查。
- Agent NDJSON 真实事件、来源、天气结构化信息与正文引用定位。原生服务继续负责工具预算、超时和取消。
- 独立快捷键提示窗和问答窗使用 React 渲染，仍通过同一 BroadcastChannel 接收实际工作台状态；快捷键保存后同步更新提示窗，两个窗口不持有录音或网络任务。主工作台重新接入原有录音开始/结束音效。

## 回退

设置中的“打开原版工作台”导航至 `/`。回退只切换主窗口页面，不改历史目录、密钥和后端 Agent 设置。重启后按桌面配置重新进入 React。若 React 页面不可用，可在本机浏览器访问 `http://127.0.0.1:4317/` 使用原版工作台。

## 待实机验收

- Windows 新主窗口加载、关闭/托盘、真实麦克风权限、音量、快捷键和外部焦点输入。
- HUD 透明区域穿透、悬停与拖动，问答独立窗口和快捷键指南。
- 真实火山 ASR、云端文字模型、联网搜索、长录音与取消；自动和模拟测试不能替代这些项目。
- macOS 桌面与硬件仍未验收，Phase 2 不启动。

构建使用 `scripts/build-windows.ps1`，脚本先检查 React 类型和产物，再构建并替换唯一 `src-tauri/target/debug/TalkCraft.exe`。应用运行时脚本拒绝替换。
