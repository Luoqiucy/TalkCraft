# 真实浏览器录音待验收清单

以下尚未实测。自动测试使用模拟DOM和录音器，不证明真实设备音频或平台兼容。

分别在Windows及macOS目标浏览器启动本地服务并记录浏览器版本、麦克风型号和操作结果：

1. 首次权限弹窗期间按钮显示等待权限且禁用；拒绝后可重试。
2. 开始讲话10秒，停止期间不能再次启动；生成音频可回放，内容无截断。
3. 快速停止再开始，旧录音事件不能停止新麦克风；回放被正确替换。
4. 连续录音到120秒，自动停止并释放麦克风；音频可回放。
5. 录音过程中设备断开，给出明确错误，不把失败音频当有效结果。
6. 关闭页面时释放麦克风；权限弹窗尚未完成就关闭页面，后到的流不得持续采音。
7. 丢弃录音后隐藏回放并释放URL；关闭页面后无音频持久保存。
8. 模拟模式无云端文字调用；云端文字模式未勾选授权不提交；任何模式下音频当前都不上传。

原型录音按浏览器实际MediaRecorder编码（例如WebM），还不是设备协议中的16kHz Opus帧。已增加本地PCM/WAV转换，但不能直接将WebM容器字节当PCM发送。

音频转换还需真实浏览器验证：准备识别音频并下载WAV，核查16000Hz/单声道/16bit、时长与回放清晰度；分别用44.1kHz和48kHz设备验证降采样。丢弃或关闭页面时不能留下转换下载链接；解码失败需允许重试，不能上传或擅自覆盖手动转写文本。Web Audio的解码/重采样不一定可中途终止，取消仅保证结果不交付，并在异步操作完成后释放上下文。
