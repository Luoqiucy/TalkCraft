每小时任务读取进度与报告；不再设置额度门槛或因额度自动跳过。每轮一个可测试任务，修Bug后复测并汇报，阶段通过后推进；全部验收通过后暂停自动化。

## AI 后端增量升级（2026-09-20）

在 Phase 1 问答能力内分 A–D 小步迁移，不改变原 Phase 1–4 和 ESP32-S3/Wi-Fi 路线：

1. A 基线与开关：固定旧流程回归，`TALKCRAFT_AGENT_ENGINE=langgraph` 才开启已迁移路径；未设置或异常值保守回到 `legacy`。不双路付费对比。
2. B 模型与工具适配：使用 LangChain.js 标准工具封装现有 `search_web` / `read_webpage` / `get_weather`，保留已验证的 DeepSeek 普通聊天与原生搜索自定义协议。
3. C LangGraph 流程：先将结构化天气问答迁入单一顶层图，完成意图、工具、证据、模型回答和取消；再迁移通用搜索/读页。工具调用上限6次、总期限45秒，图递归上限独立设置。
4. D RAG 最小闭环：用户主动选择的历史、TXT、Markdown 和可提取文字 PDF，经提取、分块、本地索引、混合检索、回答和原文引用。聊天模型与 Embedding 单独配置，不默认上传全文。

详细边界、已迁移路径、回退方式和未完成项见 `docs/AI-BACKEND.md`。
