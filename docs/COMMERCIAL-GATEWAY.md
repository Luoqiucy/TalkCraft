# Phase 2 账号与受控调用网关（开发版）

日期：2026-09-29。此模块是与桌面本机服务分离的**本机开发网关**，还不是可公网部署的商业系统。

2026-09-30 增加个人记忆开发接口：`POST /me/memories/sync` 只接受会话确认的账号ID，并在服务端校验权益；默认未配置权益即拒绝。桌面可选择同步的条目使用操作ID幂等、baseVersion冲突检测、账号独立增量cursor和删除墓碑，在SQLite事务内提交。当前仅本机开发网关与两个隔离客户端做集成验证；没有公网部署、支付或正式会员权益，不能称为会员云同步已上线。完整数据规则见 `docs/PERSONAL-MEMORY.md`。

## 当前可运行链路

`POST /auth/register` 注册邮箱及密码；`POST /auth/login` 返回短期 Bearer 会话；`POST /auth/logout` 撤销会话。`GET /me`、`GET /me/usage` 只能读取当前会话对应账号。密码使用带随机盐的 scrypt 存储，会话只在 SQLite 中保存令牌哈希。登录尝试在当前进程内限速；账号目前没有邮件验证、找回密码或多因素认证。

`POST /tasks/process` 接收提示词预设、翻译或问答；`POST /tasks/transcribe` 接收有效 16kHz 单声道 16bit PCM。两者要求登录、任务 ID 和本次上传确认。问答请求明确打开 `webSearch` 且提供器支持工具调用时，复用现有 Daisy 联网工具链；其他模式不默认搜索。真实提供器在**服务端**执行，客户端不发送供应商密钥。`POST /tasks/cancel` 中断当前任务并释放预留额度；断线或提供器失败也释放。模拟提供器不允许进入商业网关。

SQLite 数据库位于单独指定的服务端路径，表包含账号、会话、任务和追加式用量事件。`BEGIN IMMEDIATE` 将并发额度检查与预留写入同一事务；唯一任务键防止重复扣费。服务端按经验证的 PCM 长度向上取整计 ASR 秒数，按非空白输入字符计 AI 字符数；这只是当前开发计量口径，**不是已确认的套餐价格或实际供应商 token 成本**。`/me/usage` 显示本期已结算、预留和剩余，额度须由启动环境显式配置；不复用桌面本机统计。先前 JSON 开发账本不自动迁移至 SQLite。

## 启动边界

开发者在**独立后端运行环境**设置 `TALKCRAFT_COMMERCIAL_DB`（项目目录和 EXE 目录之外的专用数据文件）、`TALKCRAFT_FREE_ASR_SECONDS`、`TALKCRAFT_FREE_AI_CHARACTERS`、`TEXT_PROVIDER` 及该供应商的服务端密钥/模型配置，并按需设置 `ASR_PROVIDER` 及其服务端凭据，再运行 `npm run commercial:dev`。未设置额度或使用 mock/Ollama 文字提供器时拒绝启动。默认端口 4330，可用 `TALKCRAFT_COMMERCIAL_PORT` 更改；固定监听 `127.0.0.1`，并拒绝非本机连接与浏览器 Origin 请求。不要把现有 `server.mjs` 或此开发服务直接暴露到公网。

2026-09-29 已增加**桌面开发版接入**：React 工作台侧栏显示账号注册/登录、服务端额度和“使用账号服务处理后续任务”开关。本机 Node 服务在 `src/commercial/desktop-bridge.mjs` 中代持会话令牌，仅保存在进程内存；React 不获得 Bearer 令牌。打开开关后，工作台/HUD 共用的录音转写与文字处理请求经本机桥接到独立网关；关闭则沿用原本机配置。网关中断不自动回退到用户本机 API Key，必须明确手动切换。登录与开关在应用重启后需重新设置；本机历史仍按原隐私设置保存，不自动上传旧记录。

任务取消时，本机桥接除中止进行中的请求外，还使用任务开始时的会话向网关发出取消通知；网关遇到连接已断开的请求也会停止进入供应商调用并释放预留。该机制不解决“服务端已结算、客户端未收到答案”的恢复问题，真实云端取消仍需实测。

桌面桥接默认只连接 `http://127.0.0.1:4330/`，开发时可由本机服务环境变量 `TALKCRAFT_COMMERCIAL_URL` 覆盖为另一 loopback HTTP 根地址。账号网关需另行启动；未启动时侧栏真实显示“未连接”，不显示演示账号或额度。用户当前打开的定价网站预览不是网关。正式桌面商业接入仍需系统浏览器授权登录、系统安全凭据存储及明确的云端上传说明；当前密码登录和进程内会话仅供隔离开发测试，不能把 Bearer 令牌写入 localStorage、历史或诊断文件。

## 上线前阻碍

- 独立 HTTPS 部署、可信代理配置、账号邮件验证/找回、持久化限速和滥用防护；当前注册接口只适合隔离的开发环境。
- 服务端密钥管理、供应商用量与本账本对账、套餐及版本化权益、费用上限、备份恢复和数据保留策略。
- 中断任务的恢复/过期处理，以及响应已结算但客户端未收到时的可恢复交付；当前重复任务只拒绝二次调用，不恢复原答案。
- 真实云端 ASR、模型及联网搜索全流程、跨设备并发、断网和支付状态验收。Node 24.14.1 的 `node:sqlite` 仍被官方标记为实验性；生产部署前需固定并复核运行版本。

参考：[Node.js 24.14 SQLite 文档](https://nodejs.org/download/release/v24.14.0/docs/api/sqlite.html)、[SQLite 事务](https://www.sqlite.org/lang_transaction.html)。
