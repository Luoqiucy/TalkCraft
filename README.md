# 无线 AI 麦克风

当前：Phase 1 浏览器体验原型。已实现火山方舟文字接口适配，真实调用尚待凭据验收；ASR、Tauri 桌面外壳、全局文字输入和无线硬件尚未接入。

需要 Node.js 22 或以上；先运行 npm ci 安装锁定依赖（包含ASR传输的ws与桌面开发CLI）。

运行 `npm start`，在系统浏览器打开 http://127.0.0.1:4317 。运行 `npm test` 执行测试，`npm run check` 检查语法。

默认四种模式返回明确标记的模拟响应。开发者可按 docs/CLOUD.md 显式开启火山方舟云端文本处理。页面展示服务状态，云端提交需勾选文本上传授权。录音仅保存在页面内存，支持本地回放和丢弃；不会上传，也不会自动转写。录音停止后可点击“准备识别音频”生成16kHz单声道16bit WAV并手动下载检查。关闭页面后录音消失，主动下载的文件需自行管理。手动填写转写文本可验证流程。

研发进度见 docs/PROGRESS.md，阶段计划见 docs/PLAN.md，测试报告见 reports/。

语音识别默认关闭。开发者可设置 ASR_PROVIDER=mock 后重启，测试“准备音频→模拟转写→预览→使用转写→处理文本”。模拟不具备识别能力，主动提交音频仅发往本机服务；真实ASR尚未实现。转写结果不自动覆盖文本，已有内容需要确认替换。详见docs/ASR.md。

问答模式支持连续追问和清空会话，仅在页面内存保留最近6轮、合计8000字符；单次问答限4000字符。云端问答提交时会发送保留上下文。其他模式不带入历史；失败或取消不加入会话。超长回答仍可查看，但清空上下文以避免残缺历史。

最小Tauri开发外壳已加入，原生编译尚未成功。运行 npm ci 安装锁定依赖，npm run desktop:doctor 检查条件，满足后使用 npm run desktop:dev。正式打包仍明确禁用，详见docs/DESKTOP.md。ASR协议与传输模块已进行本机测试，但尚未接入真实识别配置。
